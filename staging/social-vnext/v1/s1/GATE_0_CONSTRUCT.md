# Social vNext Gate 0 Construct Freeze

## Scope

This authorized pilot contains 34 base candidates and 102 source records:

```text
34 pairs × associative/distractor/absence = 102 JSON files
```

It does not authorize the remaining 498 social records or other domains.

## Construct

Each target conclusion must be person-indexed:

```text
ev_A(user) + ev_B(user) -> latent_C(user)
```

Each social scenario combines:

1. a user-specific social exposure/recovery pattern; and
2. a distinct, scheduled interpersonal responsibility.

Neither fact alone may support the original fit-risk conclusion.

## Scenario Families

The pilot covers ten families: hosting before mediation, group-chat before support,
networking before repair, public recognition before feedback, overnight guests before
mentoring, late dinner before coordination, drop-ins before a recommendation letter,
video hangouts before reunion, late parties before airport help, and open-house hosting
before sensitive family planning.

## Required Controls

```text
full         A+B from the same user -> infer_C
a_only       remove B -> withhold_C
b_only       remove A -> withhold_C
link_broken  same user, matched relation replacement -> withhold_C
source_swap  optional subset, other person owns B -> source_withhold
distractor   query-relevant non-evidence -> infer_C
absence      both target episodes unavailable -> withhold_C
```

## Gate 0 Decision

Human reviewers must approve the construct matrix before any behavioral proof. An empty
or failed review blocks release.
