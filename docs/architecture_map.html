Associative Memory for Personal Agents — the build map

An agent that stores "you like coding, piano, football, groceries" is easy. The hard, useful capability is to associate across those facts and infer a new, plausible preference — and then act on it. This is the engineering map for building that benchmark + reference agent, every block grounded in a verified SOTA codebase.

RQ: Can an agent use existing user information to infer new, plausible preferences, needs, or behaviors — not just retrieve stored facts?
5-stage agent pipeline 7 SOTA codebases dissected 4 base datasets unified runs offline (mock LLM)

The special map — STORE → RETRIEVE → ASSOCIATE → REASON → ACT

The path the data takes. Each stage names its data structure and the SOTA source it borrows from. The ASSOCIATE stage (spreading activation) is the one that turns storage into inference.

STORE
extract atomic facts → embedded MemoryNotes
data structure: MemoryNote{content, embedding, category, links, poignancy, strength} · borrows Mem0 FACT_RETRIEVAL_PROMPT
▼
ASSOCIATE¹
build graph links between similar notes (on insert)
data structure: TemporalEdge{source,target,relation,weight,valid_at} · borrows A-MEM process_memory + Graphiti EntityEdge
▼  (a request arrives)
RETRIEVE
score notes = recency × relevance × importance
borrows Generative Agents new_retrieve (weights [0.5, 3, 2]); access refreshes recency
▼
ASSOCIATE²
spread activation via Personalized PageRank from the retrieved seeds
surfaces facts that are linked but not directly matched → candidate NEW preference · borrows HippoRAG run_ppr
▼
REASON
infer the preference / pick the answer; reflect insight (stored back WITH evidence)
borrows Generative Agents run_reflect → explainable inference
▼
ACT / UPDATE
emit action + consolidate (Ebbinghaus forgetting, recall reinforces)
borrows MemoryBank forgetting curve (bug-fixed: R=exp(−t/(5·S)))

Reasoning Score (RS) — the metric

For a long-horizon item where step k adds constraint c_k and the final answer must satisfy all of them. xₖ∈[0,1] = satisfaction of c_k; p̂ = self-reported confidence all hold; g = ∏xₖ. Grounded in HotpotQA joint-EM, IFEval, FollowBench, PRM800K, and ECE/Brier calibration.

w̃ₖ = γ^(k−1) / Σⱼ γ^(j−1)

RS = (1−λ)·Σₖ w̃ₖ·xₖ  +  λ·∏ₖ xₖ  −  β·(p̂ − g)²

λ=1 → strict joint-EM (HotpotQA) · λ=0 → pure partial credit (IFEval/FollowBench)
worked example: x=[1,1,0,1], p̂=0.7, γ=0.8, λ=0.4, β=0.5 → RS = 0.6·0.783 + 0.4·0 − 0.5·0.49 = 0.225

Implemented in eval/metrics.py :: reasoning_score. The harness also reports accuracy, abstention, ECE/Brier calibration, and bootstrap 95% CIs — the validity controls.
